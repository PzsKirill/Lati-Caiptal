# Lati Capital — webinar landing

One-page registration landing for the Lati Capital webinar.

- `theme/` — WordPress theme (hand-coded, no page builder). Upload the folder to `wp-content/themes/` and activate it.
  Content placeholders, form delivery and analytics are edited in **Appearance → Customize → Webinar landing**.
- `theme/index.html` — static preview of the page (the form doesn't submit there). Not needed on the server.
